# 第一周进展与测试记录 · 2026-11-16

## 丙组交付

1. 明确与甲、乙、丁的交接接口：零起始 `(行, 列)`、直接接收甲组 `RasterData`（包括数值 NoData 标记）、可替换逐步代价函数、返回路径格点与逐段/总成本。
2. 完成 8 邻域 Dijkstra（最小堆 + 父节点回溯）和可切换 A*；默认成本是相邻格均值乘移动系数，斜向系数 `√2`。默认禁止穿越障碍拐角。
3. 自定义乙组代价函数时 A* 使用零启发式，避免在未知成本下误给出非最优路径；正式成本规则确认后再决定能否使用更强的启发式。
4. 完成 7 类自动化测试，包括甲组 4×4 / 5×5 样例；其中一类使用 30 组固定种子的 4×4 随机格网、3 种斜向系数，与独立 Bellman-Ford 求得的最优成本对照，并逐段核对路径合法性和成本。

## 正确性

- 手算 2×2 格成本 `5,7 / 8,4`：从左上到右下，默认斜向边权 `(5+4)/2×√2 = 6.36396103`，两种算法均得到此值。
- 甲组 4×4 通用样例：起点 `(0,0)`、终点 `(3,3)`，默认规则下总成本 `28.27817459`；路径格点为 `(0,0) → (1,0) → (2,0) → (3,1) → (3,2) → (3,3)`，绕开 `(1,1)` 的 NoData。该值只作为当前默认规则的联调结果，待乙组手算确认。
- 障碍格导致切角时，默认改走正交路径；启用 `allow_corner_cutting=True` 后才允许斜穿。
- 两种算法在全部随机小格与 100²/500²/1000² 两类测速格上取得相同最小总成本。等价路径的节点数可不同。
- 空格、越界、非法成本和无路径分别有明确异常，避免给插件输出无效图层。

## 速度测试

运行环境：Windows、Python 3.8.8，标准库实现；单次运行、未预热，数字仅用于本机首轮对照。成本栅格在两种算法间复用，`elapsed_ms` 不包括生成栅格、校验/压平栅格或图层渲染。随机格使用固定种子 `20261116`、成本 1–9、约 5% NoData，并保留可连通边界。完整记录在 [`benchmarks/week1-2026-11-16.json`](../benchmarks/week1-2026-11-16.json)。

| 格网 | 场景 | Dijkstra 成本 / 耗时 | A* 成本 / 耗时 | A* 扩展节点 |
| --- | --- | ---: | ---: | ---: |
| 100² | 均一成本 | 140.0071 / 84.4 ms | 140.0071 / 2.0 ms | 100 |
| 100² | 随机成本 | 434.0793 / 84.3 ms | 434.0793 / 94.2 ms | 9,543 |
| 500² | 均一成本 | 705.6926 / 2,394 ms | 705.6926 / 10.5 ms | 500 |
| 500² | 随机成本 | 2,008.2409 / 1,814 ms | 2,008.2409 / 1,835 ms | 237,521 |
| 1000² | 均一成本 | 1,412.7993 / 7,280 ms | 1,412.7993 / 16.0 ms | 1,000 |
| 1000² | 随机成本 | 4,137.4326 / 7,312 ms | 4,137.4326 / 7,459 ms | 950,003 |

均一成本下，八方向距离启发式可准确指向终点，A* 扩展节点显著减少；随机成本 1–9 中全局最低成本 1 使启发式较弱，A* 没有速度优势。后续应在正式课程数据上复测，不能把 A* 宣称为总是更快。
